# wplace overlay

a userscript i made for wplace.live. you give it a picture, it turns it into wplace colors and shows it on the map so you can draw it. that's it.

not affiliated with wplace. use at your own risk.

## install

1. get tampermonkey (or violentmonkey)
2. open `wplace-simple-overlay.user.js`, hit raw, let tampermonkey install it
3. reload wplace.live, a little panel shows up. you can drag it around

## how to use

1. pick your picture
2. click "pick an area to place picture", then click two opposite corners on the map
3. tap a color in the list to see only where that color goes

tick the premium box if you actually have the premium colors. otherwise leave it.
it remembers your last overlay so you don't have to redo it every time.

## stuff to know

- it doesn't place pixels for you. it just draws a guide. you still click everything yourself
- everything stays in your browser. no tracking, no servers, nothing gets sent anywhere
- the color list and names were written from memory so some might be a bit off. go by the color you see
- if wplace changes how their map works this will probably break. open an issue if it does, no promises i'll fix it fast
- read the code before you install random userscripts. this one's one file, it's short

## found a security problem?

use the "report a vulnerability" thing in the security tab, not a public issue
